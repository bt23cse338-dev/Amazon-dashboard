# Amazon-sales-analysis-dashboard 📊

An interactive **Amazon Sales Analysis Dashboard** built to analyze sales performance, product trends, customer reviews, and category-wise revenue using data visualization.

## 📌 Project Overview

This dashboard provides a comprehensive view of Amazon product sales performance through key KPIs and interactive visualizations. It helps identify sales trends, top-performing products, product categories, and customer review patterns.

## 📊 Key Features

- **YTD Sales** and **QTD Sales** analysis
- **YTD Products Sold** tracking
- **YTD Customer Reviews** analysis
- Monthly and weekly sales trends
- Sales performance by product category
- Top 5 products by YTD sales
- Top 5 products by YTD reviews
- Interactive filters for:
  - Product Category
  - Quarter (Qtr)
- KPI-based executive dashboard

## 🔑 Key KPIs

- YTD Sales: **$2.18M**
- QTD Sales: **$811.09K**
- YTD Products Sold: **27.75K**
- YTD Reviews: **19.42M**

## 🛠️ Tools & Technologies

- Power BI
- Data Visualization
- Data Analysis
- DAX
- Power Query
- Microsoft Excel

## 🎯 Objective

The objective of this project is to transform raw Amazon sales data into an interactive business intelligence dashboard that provides meaningful insights into sales performance, product categories, and customer engagement.
